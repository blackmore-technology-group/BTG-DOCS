CORRECT CANONICAL COMPUTE MODEL · OCT 26, 2026

FarmNodes are logical DataChip/Circuit compute units — not physical computers

A Farm is an addressable assembly of logical DataChip and Circuit FarmNodes; a Farm family can define millions of reusable logical Farm instances without allocating one computer to each. Actual workloads run through the original ADAM/BTDU runtime on finite authorized physical Hosts. The three-machine engineering gate concerns three independent physical Hosts, not a three-FarmNode limit.

A local demonstration addressed 1,000,000 virtual Farms and 4,000,000 logical slots, executing four original Circuits and recording eight original Host receipts. This is not four million simultaneous jobs, independent new inventions, real settled trades or production host qualification.

The completed Foundry experience

An authorized developer imports an existing program. Studio stores a source reference, maps missing components and defines tests. NIKI proposes repairs. DataChips and Circuits are created and independently tested. ADAM/BTDU reconstruct the resulting Genome; FarmNodes execute suitable tasks using measured local or consented off-device resources. ENTITY applies permission and ownership evidence. The resulting technology can be packaged for approved target devices. Bridge manages permitted information or computing offers; Bit Trade Global may record actual licensed use and distinguish economic instruments from simple software access.

What Bit Trade Global retains

Data and intellectual property remain recognized as possible assets. The Exchange retains listings, detailed issuer/asset profiles, use licences, transferable rights and legally constituted investment instruments as different categories. A compute contribution refers to authorized real jobs completed by an attested device, not automatically to ownership of a stock. An actual technology-use transaction requires a valid entitlement and separate billable or settlement evidence.

What makes it one coherent platform

Original ENTITY is the authority for identity and rights. Original ADAM/BTDU remains the canonical reconstruction and execution substrate. NIKI model responses are engineering proposals requiring independent tests. DataChips have typed contracts, not informal cross-product scripts. FarmNodes are governed hosts, not equivalent to abstract model seat names. Bit Trade Global is the commercial/economic surface—not a second identity authority. Historical AION, ARCI, ForgeNet and other components join only through compatible tested interfaces.
